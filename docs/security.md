# Security Considerations

- No API keys, tokens, or secrets in the repository. `.env` is git-ignored.
- LinkedIn OAuth tokens belong in a secure store with least-privilege scopes.
- Do not publish private comments, messages, or personal data of commenters.
- **Integrity controls:** no invented facts; no off-schedule publishing; schedule changes need authorization.
- **Public replies:** automated replies appear under the owner's name. Review reply quality periodically and keep the ability to pause.
- Follow LinkedIn's API terms and automation policies.
